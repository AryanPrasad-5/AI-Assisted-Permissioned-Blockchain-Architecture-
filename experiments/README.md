# Experiments & Artifacts Directory

This directory stores experiment outputs, figures, and logs generated by scripts and notebooks.

```text
experiments/
├── README.md       # Directory documentation
├── results/        # JSON, CSV, and tabular metric evaluation outputs (ignored in git)
├── figures/        # High-resolution PNG/PDF plots for papers and reports (ignored in git)
└── logs/           # Detailed execution traces and run logs (ignored in git)
```

All experimental output folders are ignored by Git (except `.gitkeep`) to prevent committing large or non-deterministic binary artifacts.
